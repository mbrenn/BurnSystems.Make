= BurnSystems.Make.BuildAgent Helper Library
:toc:
:toclevels: 3

== Overview

`BurnSystems.Make.BuildAgent` is a helper library designed for developers authoring custom build agents for `BurnSystems.Make` (`bsmake`). When creating a build agent in a `.bsmake` directory (such as `.bsmake/Build.cs` and `.bsmake/Build.csproj`), this library provides pre-built utilities for argument parsing, file merging, directory operations, process invocation, and platform detection.

=== Adding the Library to a Build Agent

To use `BurnSystems.Make.BuildAgent` in your build agent, reference the package in your `.bsmake/Build.csproj` file:

[source,xml]
----
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net10.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
  </PropertyGroup>

  <ItemGroup>
    <PackageReference Include="BurnSystems.Make.BuildAgent" Version="1.0.5" />
  </ItemGroup>
</Project>
----

All classes reside in the `BurnSystems.Make.BuildAgent` namespace.

== Classes and Methods

=== ProgramArguments

`ProgramArguments` parses command-line arguments forwarded by `bsmake` to the build agent executable (such as `-c <configuration>`).

==== Properties

[cols="1,1,2", options="header"]
|===
| Property | Type | Description
| `Configuration` | `string` | The active build configuration (e.g. `"Debug"`, `"Release"`). Returns `string.Empty` if no configuration was provided.
|===

==== Static Methods

===== `ProgramArguments.Parse(string[] arguments)`

Parses the command-line argument array passed into the build agent's entry point (`args`).

* *Parameters:*
** `arguments` (`string[]`): The raw CLI arguments (e.g. `args`).
* *Returns:* `ProgramArguments` object containing parsed configuration values.

==== Example

[source,csharp]
----
using BurnSystems.Make.BuildAgent;

var arguments = ProgramArguments.Parse(args);
Console.WriteLine($"Building in configuration: {arguments.Configuration}");

if (arguments.Configuration == "Release")
{
    // Perform release-specific artifact generation
}
----

=== FileHelper

`FileHelper` provides methods for merging files (e.g. combining header definitions or templates with source data) with built-in timestamp caching to support incremental builds.

==== Static Methods

===== `FileHelper.MergeFiles(FileMergeOptions options)`

Merges two source files into a target output file. It can prepend an optional prefix (such as an autogenerated comment header) and checks file modification timestamps so that merges are skipped if the target file is already up to date.

* *Parameters:*
** `options` (`FileMergeOptions`): Options controlling source paths, target path, prefix text, and timestamp evaluation.
* *Returns:* `bool` - `true` if the target file was created or updated; `false` if the merge was skipped because the target is up to date.
* *Exceptions:*
** `ArgumentNullException`: Thrown if `options` is `null`.
** `FileNotFoundException`: Thrown if `FirstFile` or `SecondFile` does not exist.
** `InvalidOperationException`: Thrown if `TargetFile` matches `FirstFile` or `SecondFile`.

==== FileMergeOptions Class

[cols="1,1,1,2", options="header"]
|===
| Property | Type | Default | Description
| `FirstFile` | `string` (required) | - | Path to the first source file to merge.
| `SecondFile` | `string` (required) | - | Path to the second source file to merge.
| `TargetFile` | `string` (required) | - | Path to the destination file. Target directories are created automatically if they do not exist.
| `PrefixTextTarget` | `string` | `"// This file is autogenerated\r\n"` | Text header prepended to the target file before source contents are written. Set to `string.Empty` or `null` to omit.
| `OnlyIfModified` | `bool` | `true` | When `true`, merging only occurs if the target file does not exist or if either source file is newer than the target file. When `false`, the file is always merged.
|===

==== Example

[source,csharp]
----
using BurnSystems.Make.BuildAgent;

var modified = FileHelper.MergeFiles(new FileMergeOptions
{
    FirstFile = "src/header.cs",
    SecondFile = "src/generated_body.cs",
    TargetFile = "GeneratedCode.cs",
    PrefixTextTarget = "// <auto-generated> This file was generated by BuildAgent </auto-generated>\r\n",
    OnlyIfModified = true
});

if (modified)
{
    Console.WriteLine("GeneratedCode.cs was regenerated.");
}
else
{
    Console.WriteLine("GeneratedCode.cs is up to date, skipping merge.");
}
----

=== DirectoryHelper

`DirectoryHelper` provides convenience operations for directory-level file management.

==== Static Methods

===== `DirectoryHelper.CopyFiles(string sourceDirectory, string targetDirectory, bool overwrite = true, string searchPattern = "*.*")`

Copies files matching `searchPattern` from `sourceDirectory` to `targetDirectory` without recursive subdirectory traversal.

* *Parameters:*
** `sourceDirectory` (`string`): The directory containing source files.
** `targetDirectory` (`string`): The destination directory where files will be copied.
** `overwrite` (`bool`, default: `true`): Whether existing destination files should be overwritten.
** `searchPattern` (`string`, default: `"*.*"`): Search pattern filter for matching files (e.g., `"*.json"`, `"*.dll"`).

==== Example

[source,csharp]
----
using BurnSystems.Make.BuildAgent;

// Copy all JSON configuration files from assets into the build output
DirectoryHelper.CopyFiles("Assets/Config", "bin/Config", overwrite: true, searchPattern: "*.json");
----

=== ProcessInvoke

`ProcessInvoke` allows build agents to run external CLI commands, scripts, or executables (such as `npm`, `npx`, code generators, or compilers). It automatically handles executable extension resolution (`.exe`, `.cmd`, `.bat` on Windows) and `PATH` lookups across different operating systems.

==== Static Methods

===== `ProcessInvoke.Run(string command, string[] arguments)`

Executes a command with the given arguments and waits for completion. Searches both the current directory and system `PATH`.

* *Parameters:*
** `command` (`string`): Command or executable name (e.g. `"npm"`, `"npx"`, `"dotnet"`).
** `arguments` (`string[]`): Array of command-line arguments to pass.
* *Returns:* `Task<int>` - Exit code of the completed process (`0` indicates success).
* *Exceptions:*
** `InvalidOperationException`: Thrown if the command could not be found.

===== `ProcessInvoke.Run(ProcessInvokeParameter parameter)`

Executes a command with full configuration via `ProcessInvokeParameter`.

* *Parameters:*
** `parameter` (`ProcessInvokeParameter`): Invocation options.
* *Returns:* `Task<int>` - Exit code of the process.

===== `ProcessInvoke.CheckFileForExistings(string directory, string command)`

Checks if a command or executable exists within the specified directory, testing platform-specific extensions (`.exe`, `.cmd`, `.bat`).

* *Parameters:*
** `directory` (`string`): Directory path to inspect.
** `command` (`string`): Base command name.
* *Returns:* `string?` - Absolute/relative path to the matching executable file, or `null` if not found.

===== `ProcessInvoke.GetFilenames(string binaryFileName)`

Enumerates potential platform-specific file names for a given binary name (e.g. `"npx"` -> `["npx", "npx.exe", "npx.cmd", "npx.bat"]` on Windows).

* *Parameters:*
** `binaryFileName` (`string`): Base name of the binary.
* *Returns:* `IEnumerable<string>` - List of candidate file names.

==== ProcessInvokeParameter Class

[cols="1,1,1,2", options="header"]
|===
| Property | Type | Default | Description
| `Command` | `string` (required) | - | Executable or command name to run.
| `Arguments` | `string[]` (required) | - | Array of argument strings.
| `SearchInPath` | `bool` | `true` | If `true`, searches directories in the `PATH` environment variable if not found in current directory.
|===

==== Example

[source,csharp]
----
using BurnSystems.Make.BuildAgent;

// Simple invocation
int exitCode = await ProcessInvoke.Run("npm", ["run", "build"]);
if (exitCode != 0)
{
    throw new InvalidOperationException($"npm build failed with exit code {exitCode}");
}

// Advanced invocation with parameter object
int npxExitCode = await ProcessInvoke.Run(new ProcessInvokeParameter
{
    Command = "npx",
    Arguments = ["tailwind", "-i", "input.css", "-o", "output.css"],
    SearchInPath = true
});
----

=== EnvironmentHelper

`EnvironmentHelper` provides platform detection utilities to write cross-platform build logic that adapts between Windows, Linux, macOS, and FreeBSD.

==== Static Methods

[cols="2,1,3", options="header"]
|===
| Method | Returns | Description
| `EnvironmentHelper.IsWindows()` | `bool` | Returns `true` if running on Windows.
| `EnvironmentHelper.IsUnix()` | `bool` | Returns `true` if running on a Unix-based platform (Linux, macOS, or FreeBSD).
| `EnvironmentHelper.Is64BitOperativeSystem()` | `bool` | Returns `true` if running on 64-bit architecture (`X64` or `Arm64`).
| `EnvironmentHelper.GetOSPlatform()` | `OSPlatform` | Returns current platform (`OSPlatform.Windows`, `OSPlatform.Linux`, `OSPlatform.OSX`, or `OSPlatform.FreeBSD`). Throws `InvalidOperationException` for unknown platforms.
| `EnvironmentHelper.IsWindows(OSPlatform family)` | `bool` | Checks if the given `OSPlatform` is Windows.
| `EnvironmentHelper.IsUnix(OSPlatform family)` | `bool` | Checks if the given `OSPlatform` is Unix-based (Linux, OSX, FreeBSD).
| `EnvironmentHelper.IsLinux(OSPlatform family)` | `bool` | Checks if the given `OSPlatform` is Linux.
| `EnvironmentHelper.IsOSX(OSPlatform family)` | `bool` | Checks if the given `OSPlatform` is macOS (OSX).
| `EnvironmentHelper.IsFreeBSD(OSPlatform family)` | `bool` | Checks if the given `OSPlatform` is FreeBSD.
|===

==== Example

[source,csharp]
----
using BurnSystems.Make.BuildAgent;

if (EnvironmentHelper.IsWindows())
{
    Console.WriteLine("Executing Windows-specific tool...");
    await ProcessInvoke.Run("tools/win/generator.exe", ["--all"]);
}
else if (EnvironmentHelper.IsLinux())
{
    Console.WriteLine("Executing Linux-specific tool...");
    await ProcessInvoke.Run("tools/linux/generator", ["--all"]);
}
----

== Complete Build Agent Example

Below is a complete `.bsmake/Build.cs` example showing how these helper utilities work together in a project:

[source,csharp]
----
using BurnSystems.Make.BuildAgent;

// 1. Parse configuration from arguments
var arguments = ProgramArguments.Parse(args);
Console.WriteLine($"Starting pre-build tasks for configuration: {arguments.Configuration}");

// 2. Run external generator via ProcessInvoke
int exitCode = await ProcessInvoke.Run("dotnet", ["run", "--project", "../Tools/CodeGen"]);
if (exitCode != 0)
{
    Console.Error.WriteLine("Code generation failed!");
    Environment.Exit(exitCode);
}

// 3. Conditionally merge template files with incremental checking
bool merged = FileHelper.MergeFiles(new FileMergeOptions
{
    FirstFile = "Templates/LicenseHeader.txt",
    SecondFile = "Generated/RawOutput.cs",
    TargetFile = "Generated/FinalOutput.cs",
    PrefixTextTarget = "// <auto-generated />\r\n",
    OnlyIfModified = true
});

if (merged)
{
    Console.WriteLine("FinalOutput.cs updated.");
}

// 4. Copy static assets to output
DirectoryHelper.CopyFiles("StaticAssets", "bin/Assets", overwrite: true, searchPattern: "*.png");

Console.WriteLine("Build agent tasks completed successfully.");
----
